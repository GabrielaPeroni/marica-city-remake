{% translate "Como chegar" context "visit page heading" %}

{% blocktranslate trimmed %} Maricá fica a cerca de 60 km do centro do Rio de Janeiro. De carro, o caminho mais comum é pela Ponte Rio–Niterói e pela RJ-106 (Rodovia Amaral Peixoto); conte de uma hora a uma hora e meia, dependendo do trânsito. {% endblocktranslate %}

{% blocktranslate trimmed %} Há linhas de ônibus intermunicipais saindo do Rio e de Niterói. Confira horários com as empresas antes de sair. {% endblocktranslate %}

{% translate "Como circular" %}

{% blocktranslate trimmed %} Os ônibus municipais vermelhos, os "Vermelhinhos", são gratuitos para todos, moradores e visitantes. Eles ligam o Centro às praias, lagoas e bairros. {% endblocktranslate %}

{% blocktranslate trimmed %} As distâncias entre as regiões são grandes, então para visitar vários lugares no mesmo dia vale planejar o roteiro com antecedência. {% endblocktranslate %}

{% translate "Quando ir" %}

{% blocktranslate trimmed %} O clima é tropical: verões quentes e com chuvas de fim de tarde, invernos amenos e mais secos. O verão é a época das praias; o inverno é ótimo para trilhas. {% endblocktranslate %}

{% blocktranslate trimmed %} A cidade tem agenda cultural o ano todo, com festas tradicionais, shows e festivais gratuitos. {% endblocktranslate %} {% translate "Veja a agenda" %}.

{% translate "Praias, lagoas e trilhas" %}

{% blocktranslate trimmed %} As praias de mar aberto, como Itaipuaçu, Ponta Negra e Jaconé, costumam ter ondas fortes e correntes: prefira nadar perto dos postos de guarda-vidas. Para águas calmas, caiaque e stand-up paddle, procure as lagoas. {% endblocktranslate %}
